使用說明

多張 → 批次

  1. 拖曳或選擇 2–20 張 JPG/PNG
  2. 設定最大寬度與品質
  3. 立即轉換，比較原始／WebP 大小
  4. 單張下載或打包 ZIP

單張 → 裁切

  1. 只選一張圖片
  2. 調整裁切框與比例、指定輸出寬度
  3. 預估大小會即時更新
  4. 下載 WebP
